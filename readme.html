Description du projet

CahierSmart est une application web complète permettant de digitaliser et centraliser la gestion des cahiers de textes dans les établissements scolaires. Elle s’adresse à quatre acteurs principaux :

👨‍🏫 Enseignant — saisit cours, devoirs, évaluations
👩‍🎓 Élève — consulte programme, devoirs, notes
👨‍👩‍👧 Parent — suit scolarité, reçoit alertes
🛠️ Administrateur — gère emplois du temps, classes
